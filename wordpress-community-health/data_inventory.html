Partial-source gaps stored in SQLite

SignalStatusBest next sourceCurrent note
developer_interest_proxy partial Stack Exchange API question totals by Stack Overflow tag plus Wikimedia Pageviews API Quarterly Stack Overflow tag volume, Wikimedia pageviews, and a compact attention/demand summary are included as public attention proxies; they do not measure general search-query interest.
job_demand partial Hacker News monthly Who is hiring? threads plus hiring-platform exports HN Who is hiring WordPress/WooCommerce, PHP, and agency/studio mention counts, WordPress Jobs board open-listing snapshots, and a compact proxy-direction summary are included; broader job-board demand still needs a labor-market source.
new_site_share_history partial BuiltWith historical trends or HTTP Archive cohort queries Current report includes BuiltWith current Net New Pipeline, HTTP Archive monthly origin counts, derived tracked-share history, rank-tier detected-origin adoption, and a compact new-site choice summary; not a multi-year newly created site cohort.
search_interest partial Google Trends or another search-interest provider Wikimedia Pageviews API quarterly article-view trends and a compact attention/demand summary are included as public-interest proxies; true search-query interest still needs Google Trends or another search provider.
support_forum_history partial Historical WordPress.org support forum topic/reply export Current report includes public support queue snapshots, resolved/unresolved/no-reply summaries, last-activity buckets, forum-level unanswered summaries, and major-plugin support-thread totals; not a full long-term topic/reply history.
