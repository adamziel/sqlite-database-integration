What has been done

Plan

Wrote the active brief in goal.md: a visual report on WordPress participation, project load, and market position.

Tickets

Built quarterly metrics from WordPress Core Trac and Gutenberg GitHub, including new/closed flow, backlog, reporters, first-time reporters, bug/feature mix, response time, closure time, stale share, and contributor concentration.

Classification

Loaded bug, feature request, documentation, support, and other classification outputs into the same SQLite-backed report pipeline.

Ecosystem

Added broader signals: Core release credits and committers, Make/Core posts and comments, dev notes, WordCamps, events, translation snapshots, Five for the Future, support forums, plugin/theme directory samples, major plugin installs/downloads, and enterprise case studies.

Adoption

Added market-position signals from W3Techs, HTTP Archive, BuiltWith snapshots, WordPress.org stats, Stack Overflow, Wikimedia pageviews, Hacker News hiring threads, and WordPress Jobs snapshots.

Builder share

Added a derived HTTP Archive tracked-share chart and SQLite table so WordPress can be compared directly with Shopify, Wix, Squarespace, and Webflow over time.

Readout

Added top-level evidence lanes, seven plain-English decision answers, and a final evidence-strength strip so measured signals are separated from proxy-led signals.

Scorecard

Added the Relevance Scorecard near the top of the report: installed reach, recent share direction, current new-site proxy, new community entry, project throughput, and ecosystem base.

Coverage map

Added a visual Goal Coverage Map so readers can quickly separate strong quarterly evidence from directional snapshots and partial proxies.

Inventory

Added data_inventory.html and make_data_inventory.py to regenerate the SQLite table list, hashed local sources, and stored partial-source gaps.

Publishing

Generated final_report.html and published the GitHub Pages version as index.html, with community_health.sqlite.gz for the supporting database export.
