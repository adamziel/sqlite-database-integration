Core is a larger, older backlog.

Core Trac has 8,223 open tickets today. That is a much bigger and older queue than Gutenberg GitHub Issues, so the backlog line moves more slowly.

Ticket flow is the main story.

New tickets averaged 627 per quarter early in the window and 446 recently. When closures rise above new tickets, the open backlog bends down.

GitHub is review traffic, not the issue source.

wordpress-develop produced 10,772 PRs in the window, with 9,125 linking back to Trac. It helps explain implementation activity without replacing Trac ticket flow.

Method and source files

Data window: June 11, 2021 through June 11, 2026. Core ticket inventory comes from Core Trac CSV exports. Closure and reopen timing comes from public ticket RSS feeds for closed tickets modified in the window and current reopened tickets. GitHub activity comes from the GitHub API for WordPress/wordpress-develop pull requests.

Generated files: quarterly_metrics.csv, monthly_metrics.csv, component_summary.csv, resolution_summary.csv, and github_pr_quarterly.csv.

Most closure dates are parsed from RSS status-change events. Tickets without a public close event in the parsed feed use the Trac modified timestamp as a fallback.
